# launcher

* 该GUI框架LV MEM占用60KB
* 使用双buffer架构，最小buffer占用 2x15KB(320x240x2x10%)
* 目前的GUI桌面中有大量的图标功能未实现，可在此基础上裁剪
* 限定音频播放文件限定10KB以上可以识别
* 限定mp3文件名称长度不超过15bytes
