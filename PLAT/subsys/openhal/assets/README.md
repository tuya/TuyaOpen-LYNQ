# openHAL

* 每个表格的第一项作为识别名称，其他项为参数，例如gpio列，设备管理中gpio16就从这个表格中列数据中提取；
* 例如i2c.csv中的数据中，sda/scl对应的数值是pad编号，参数中的pad/pin等没有特殊说明情况都代指paddr索引，相关名称只方便阅读，不构成参数判断标准；
* 时钟管理逻辑是在当前时钟树中找最接近的，如果配置时最高时钟时26MHz，则通过对26MHz分频得到外设时钟（上限为26MHz），如果设定时钟高于26MHz，则返回错误；
* 为便于存储和空间管理，所有外设的解析参数格式为uint32_t，通过32bit位实现基本参数配置，不足空置，不够压缩裁剪；
* 使用open_hal_parse()函数时，如果不传入dump数据指针，则默认对解析的数据执行配置操作，如果传入指针则只导出数据；
